# ✈︎ 마일 좌석 추적 (에어프랑스 Flying Blue)

에어프랑스 Flying Blue 마일로 발권할 수 있는 **스카이팀 한일 직항**(대한항공, 12/17부터 대한항공 편명으로 바뀌는 (구)아시아나)의 마일리지 좌석을 날짜별로 보여주는 앱이에요.
기존 **항공권 가격 추적**(`flight-tracker/`)과는 따로 동작해요. 그쪽 코드·노선·메일은 건드리지 않아요.

```
집 PC 크롬 (로그인된 상태, 확장 프로그램)
  └─ 하루 1회: 에어프랑스 '마일리지로 예약' → 날짜를 비우고 한 달 치 캘린더 조회
  └─ 목표 마일 이하인 날짜만 편 상세까지 열어 세금 · 유류할증료 · 편명 확인
  └─ 결과를 이 저장소(award-tracker/site/data)에 저장
GitHub Pages → 휴대폰 앱 (https://<아이디>.github.io/flight-tracker/award/)
  └─ 노선별 날짜 달력(마일 + 추가 비용), 왕복 조합, 목표 이하 새로 열림 메일
```

## 진행 단계

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 기록 모드 확장: 직접 한 번 검색하면 페이지가 받은 데이터를 파일로 저장 | ✅ 완료, **기록 파일이 필요해요** |
| 2 | 휴대폰 앱 화면 (지금은 샘플 데이터) | ✅ 완료 |
| 3 | 자동 조회: 정해진 순서대로 클릭 → 대기 → 결과 읽기 → 저장소에 저장 | 기록 파일을 받은 뒤 |
| 4 | 목표 마일 이하 알림 메일, 로그인 만료 · 보안 확인 알림 | 3단계 다음 |
| 5 | 집 PC 설치 마무리, 1주일 시험 운영 | |

에어프랑스 마일리지 검색은 로그인해야 쓸 수 있어서, 실제 화면과 데이터 모양은 집 PC에서 한 번 기록해 봐야 알 수 있어요. 그 기록으로 3단계 자동 조회를 만들어요.

## 1. 크롬 확장 설치 (집 데스크탑, 한 번만)

1. 이 저장소를 내려받아요. GitHub 저장소 화면 → **Code → Download ZIP** → 압축 풀기 (또는 `git clone`).
   아직 `main` 에 합치기 전이면 왼쪽 위 브랜치 목록에서 작업 브랜치를 고른 뒤 내려받아요.
2. 크롬 주소창에 `chrome://extensions` 를 입력해요.
3. 오른쪽 위 **개발자 모드**를 켜요.
4. **압축해제된 확장 프로그램을 로드합니다** → 내려받은 폴더 안의 `award-tracker/extension` 폴더를 골라요.
5. 주소창 오른쪽 퍼즐 조각 아이콘 → **마일 좌석 도우미** 옆 핀을 눌러 고정해요.

> 확장 프로그램은 에어프랑스 사이트(`airfrance.co.kr`, `airfrance.com` 등)에서만 동작해요. 다른 사이트는 보지 않아요.

## 2. 기록하기 (10분 정도)

1. 크롬에서 에어프랑스 사이트에 **로그인**해요.
2. **마일 좌석 도우미** 아이콘 → **기록 시작**. 아이콘에 빨간 숫자가 생기면 기록 중이에요.
3. **마일리지로 예약**에서 출발 **인천**, 도착 **도쿄(나리타)**, **날짜는 비우고**, **1명 · 이코노미**로 검색해요.
   - 날짜별 최저 마일 캘린더가 나오는지가 중요해요. 대한항공 편이 안 보여도 그대로 진행해 주세요 (그것도 확인할 내용이에요).
4. 캘린더에서 날짜 하나를 눌러 편을 고르고, **세금 · 유류할증료가 보이는 화면**까지 가요. **결제는 하지 않아요.**
5. 좌석 등급을 **비즈니스**로 바꿔서 3~4를 한 번 더 해요.
6. 가능하면 **김포 → 도쿄(하네다)** 도 한 번 검색해요.
7. 아이콘 → **기록 멈춤** → **기록 파일 저장 · 관리** → **파일로 저장**.
   - 관리 화면에 "마일 · 세금 · 항공편으로 보이는 데이터 N건이 기록됐어요"라고 나오면 성공이에요.
8. 다운로드 폴더의 `award-recording-날짜-시각.json` 파일을 **Claude 대화에 첨부**해 주세요.

### 기록에 들어가는 것 / 안 들어가는 것

- 들어가는 것: 검색 결과 데이터(JSON), 누른 버튼의 이름과 위치, 버튼을 누른 뒤 화면에 보이는 글자
- 가려서 저장: 이름 · 이메일 · 회원번호 · 전화번호 · 생년월일 · 로그인 토큰 · 잔여 마일
- 아예 기록 안 함: 로그인 · 회원가입 · 결제 화면, 비밀번호 · 이메일 · 전화번호 입력칸, 광고 · 분석 요청, 스크린샷
- 기록은 집 PC 크롬 안에만 있어요. **파일로 저장할 때만** 밖으로 나와요.
- 저장소가 공개라서 **기록 파일은 GitHub 에 올리지 말고** Claude 대화에만 첨부해 주세요.

## 3. 휴대폰 앱

`main` 브랜치에 합치면 `https://<아이디>.github.io/flight-tracker/award/` 에 배포돼요 (기존 가격 추적 앱 주소는 그대로).
지금은 **샘플 데이터**가 보여요. 3단계 자동 조회가 시작되면 실제 결과로 바뀌어요.

- **iPhone (Safari)**: 공유 버튼 → "홈 화면에 추가"
- **Android (Chrome)**: ⋮ → "홈 화면에 추가" 또는 "앱 설치"

화면 구성
- **목록**: 집 PC 조회 상태(정상 / 로그인 필요 / 보안 확인 필요 / 하루 넘게 조회 없음), 노선별 등급별 최저 마일과 목표 이하 날짜 수, 새로 열린 좌석 수
- **노선 상세**: 가는 편 / 오는 편, 이코노미 / 비즈니스 달력. 날짜를 누르면 마일, 추가 비용(세금 · 유류할증료), 남은 좌석, 지난 조회 대비 변화, 편명. 왕복은 마일이 가장 적은 조합 5개
- **노선 추가 · 조건 바꾸기**: 한일 노선 목록에서 골라 기간 · 등급 · 목표 마일을 정하면 `routes.json` 에 넣을 내용과 하루 조회 횟수를 보여줘요

## 노선 설정 (`award-tracker/routes.json`)

앱의 **+ 노선 추가하기**에서 만든 내용을 `"routes": [ … ]` 안에 붙여 넣고 저장(Commit)해요.

```jsonc
{
  "id": "icn-nrt-20270620",
  "name": "인천 → 도쿄 나리타",
  "from": "ICN", "to": "NRT",
  "start": "2027-06-20", "end": "2027-07-10",              // 가는 편 출발 기간
  "return_start": "2027-06-25", "return_end": "2027-07-15", // 오는 편 (편도면 null)
  "cabins": ["economy", "business"],
  "target_miles": { "economy": 15000, "business": 35000 },  // 이하로 열리면 메일 (null 이면 알림 없음)
  "nonstop": true, "adults": 1,
  "active": true                                              // false = 일시 중지
}
```

`settings` 의 `daily_search_limit`(모든 노선을 합친 하루 조회 한도), `max_details_per_route`(노선마다 하루 상세 확인 최대 횟수), `run_at_kst`(조회 시각)로 조회 양을 조절해요.
캘린더는 한 달에 1번, 좌석 등급마다 따로 조회해서, 노선 하나의 하루 조회 횟수는 대략 `달 수 × 등급 수 (+ 오는 편) + 상세 확인`이에요.

## 안전 원칙 (자동 조회 단계에서 지킬 것)

- 본인 계정으로 조회하는 거라, 막히면 마일 계정에 문제가 생길 수 있어요. 그래서 **하루 1회**, 클릭 사이 **무작위 대기**, **하루 조회 한도**를 둬요.
- 보안 확인(캡차)이 뜨면 **우회하지 않고 바로 멈추고** 메일로 알려요.
- 로그인이 풀리면 비밀번호를 자동으로 넣지 않고 "다시 로그인해 주세요" 알림만 보내요. 비밀번호는 어디에도 저장하지 않아요.
- PC나 크롬이 꺼져 있던 날은 건너뛰고, 앱에 "하루 넘게 조회 없음"으로 표시해요.

## 폴더 구조

```
award-tracker/
  extension/   크롬 확장 (manifest.json, 기록: hook.js · bridge.js · background.js, 개인정보 가림: redact.js)
  site/        휴대폰 앱 (GitHub Pages /award/), site/data 에 조회 결과
  routes.json  추적할 노선
  tests/       개인정보 가림 테스트
```

## 로컬 테스트

```bash
cd award-tracker
npm test                                      # 개인정보 가림 테스트 (Node 18 이상)
cd site && python3 -m http.server 8000        # http://localhost:8000
```
